# PlagaScan IA – Ayacucho

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `plagascan-ia-ayacucho`.
2. Sube todos los archivos de esta carpeta al directorio raíz.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Branch: `main`; carpeta: `/ (root)`.
6. Pulsa **Save**.
7. Espera la publicación.

La dirección será:
`https://TU-USUARIO.github.io/plagascan-ia-ayacucho/`

La cámara necesita HTTPS cuando la app se abre desde Internet.
